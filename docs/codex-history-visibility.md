# Codex 历史可见性

“设置 → 诊断 → 在 Codex/Claude 中隐藏会话”默认关闭。开启后，NeoRead 创建的已完成 Codex 对话会归档，从 Codex 的普通历史列表移出；关闭后恢复可见。NeoRead 内的消息、引用、思考内容和阅读进度保留。Claude 的原生保存、隐藏与恢复见 [Claude 原生阅读会话](claude-conversations.md)。

归档后的线程不能直接继续提问。NeoRead 会先取消归档，再恢复同一个线程和已提交的上下文；本轮回答完成后再次归档。续聊期间会暂时恢复可见。切换设置不会中断正在生成的回答，当前轮结束后按最新设置处理。

使用 [Codex App Server 官方接口](https://learn.chatgpt.com/docs/app-server) 的 `thread/archive`、`thread/unarchive` 和 `thread/resume`，保持原线程 ID。只处理 NeoRead 自己记录的线程，不读取 Codex 凭据文件，也不删除 Codex 线程。线程归属标记只在本机书库保存，不随 WebDAV 或书库压缩包迁移到其他独立书库。

迁移后原生线程不存在时，从 NeoRead 保存的问答、引用和工具记录建立新线程。仅在 Codex 明确返回线程不存在时重建；连接失败或线程正在其他窗口使用时保留原绑定并提示重试，不把这些错误当成历史丢失。

本机 Codex CLI 0.166.0 已验证：归档后直接恢复返回错误，先取消归档再恢复成功，并保持同一线程 ID；该验证只创建测试空线程，没有调用模型。自动回归验证切换开关、重启后继续对话、完整问答保留及导入书库的归属隔离。

手动检查：开启选项后在阅读侧栏向 Codex 连续提问，确认每轮仍能引用前文，回答完成后从普通 Codex 历史中移出；关闭选项后检查原对话恢复可见，再次提问仍延续同一会话。
