# 坚果云同步

在“设置 → 论文库 → 坚果云同步”先开启开关，再填写坚果云账号邮箱和第三方应用密码，测试连接成功后点击“保存”。账号或密码变化后需要重新测试；修改设备名称或间隔不需要重测。测试连接会初始化书库目录并校验读写，尚不启用或保存本机设置；保存仅写入本机配置，不向坚果云发送请求。未开启时收起配置项，保存后显示书库旁和阅读界面的同步图标。应用密码可在坚果云网页的“账户信息 → 安全选项 → 第三方应用管理”中生成，见[官方说明](https://help.jianguoyun.com/?p=2064)。

测试连接时创建 `NeoRead/<当前书库名称>/`，默认是 `NeoRead/论文库/`。同步覆盖左上角选中的整个独立书库，包括其中的论文和图书。桌面版共用本机已配置的 WebDAV 连接；其他独立书库默认关闭，可切换后选择开启，各自保留目录和间隔。只有当前打开的独立书库会执行自动同步。

每次启动应用或重新打开已启用同步的书库，会先执行一轮双向同步，既上传本地修改，也接收云端修改。之后默认间隔 15 分钟，提供 5、10、15、30、60 分钟建议，也可填写 1–525600 的整数分钟。保存设置后按该间隔执行；已验证连接可直接修改设备名称和同步间隔，账号或密码变化后才需要重新测试。设备改名保存后会尽快同步到云端的设备索引，不更换设备身份，也不重传原文件。点击“立即同步”可马上开始。关闭开关立即停用当前书库同步，保留共享连接和云端文件。启动、定时和手动同步均使用同一条双向流程。

书库界面的同步按钮位于左上角书库选择右侧，阅读界面位于“返回书库”右侧。未配置 WebDAV 时隐藏；已配置但当前书库未开启时显示空心双箭头，点击进入“设置 → 论文库”选择开启。同步时外圈旋转、中心留空，悬停显示本轮已传输和总计的 MB；扫描阶段显示“总量统计中”，总量包含上传与下载的文件分块，不包含已复用分块和元数据请求，应用阶段跳过的内容会更新总量；成功后显示勾，有新修改后变为感叹号，失败显示叉，直到下一次成功同步才清除失败标记。手动同步成功显示绿色消息，手动或自动同步失败在右下角显示红色消息；自动同步成功保持安静。

## 另一台设备

在另一台设备从书库菜单下载云端书库，或创建、选择对应的独立书库，使用相同坚果云账号保存设置，然后点击“立即同步”。本地已有文档会参与双向合并；空书库会接收云端内容。可为设备填写不同名称，便于处理冲突。

原始 PDF/EPUB、论文信息和添加日期、分类与标签、回收站状态、批注、阅读位置、论文笔记、已保存的译文与公式、解析图片和缓存、文档附件、概要、已保存的聊天会话及消息均参与同步。独立书库中的论文视图与图书视图一起同步。

新接收的 PDF 按论文逐项处理：先完整下载并校验原 PDF，立即加入书库并允许打开；随后补齐译文与排版，最后补齐批注、笔记、附件和聊天，再处理下一篇。同步图标的悬浮提示显示当前论文及接收阶段。整库传输量在逐篇元数据尚未发现完时显示“总量统计中”，计划完整后更新为剩余上传、下载的合计。译文未到齐时暂停本机后台解析，原文阅读继续可用。停止、断网或重启后保留已收到的原文和阶段记录，下一次接续；接收期间新增的阅读进度和笔记仍作为本地修改处理。整库导出保存已经到达的内容，导入副本恢复本机解析状态；原书库仍保留未完成的同步进度。

AI 账号与 API 密钥、CLI 登录与原生续聊线程、代理、机器路径、运行中的任务和诊断日志留在本机。进行中的解析、翻译和问答会延后同步对应文档；接收已有解析结果后可以直接阅读，未完成的翻译需手动继续。没有解析结果的 PDF 在本机排队解析，不自动调用翻译服务。搜索用的全文索引在接收端重新构建。

另一设备修改或撤回聊天后，受影响会话的本机 Agent 上下文从已同步记录重新建立；其他会话的上下文保留，聊天正文不被删除。

## 删除

移入回收站和恢复操作同步到其他设备，回收站中的原文件保留。永久删除会上传有版本顺序的删除记录，其他设备在同步时删除相应文档、批注、译文、对话和本地原文件／缓存；新设备不会重新下载已删除文档，离线失败后重试也保留删除决定。

删除与另一设备尚未同步的编辑相遇时保留冲突，由用户选择保留编辑或确认删除，不自动覆盖未同步修改。接收删除时，文件操作与数据库提交共用恢复日志，中断后按数据库是否提交恢复或完成删除。共用附件只有在最后一篇引用它的文档删除后才移除。

云端保留删除记录及旧分块缓存，用于防止离线旧副本恢复和处理冲突；永久删除的文档不再作为有效书库内容同步。目前不自动清理云端旧分块。

书库下拉菜单的“删除当前书库”会再次询问，并允许选择是否同时删除已连接的坚果云副本。默认只将本机书库移到系统废纸篓，云端副本保留。删除云端副本时清理该书库的文件夹，并保留一个小的删除标识；其他已连接设备保留本机数据，但停止向这个已删除的书库同步。同名新书库使用新的云端标识。云端删除成功后若本机删除失败，会明确提示，可重试本机删除。至少保留一个本机书库，默认书库也可重命名或在有其他书库时删除。

## 更名和冲突

双击左上角书库标题重命名后，下次同步会将云端文件夹一并更名。已连接设备通过稳定书库标识找到新路径，不重新创建旧目录。未激活书库的更名会排队，切回该书库后的下次同步执行。云端已有同名文件夹时停止更名并提示，需为本地书库换名。

修改不同笔记、批注或聊天会话时可以自动合并；多台设备同时修改同一内容时，在设置中高亮“选择版本”，可稍后处理，不自动打开对话框。可查看设备名、时间和笔记或聊天摘录，再选择“只使用此版本”。仅笔记正文冲突时，选择其中一份也会保留其他不冲突的批注和文档信息。笔记冲突还提供“都保留”：将不同正文按设备和时间分段保存在同一篇笔记中，并同步已处理结果；同一组版本不会重复提示。此操作沿用现有笔记 10 万字符上限，存在其他无法自动合并的内容冲突时需选择文档版本。未选择前保留本地内容和云端各版本。阅读位置按实际阅读时间选择，最远阅读进度保留较大值。标记未读会清零阅读位置与进度，并同步一次新的重置记录，避免离线旧进度覆盖这次清零；参与同步的设备需更新到支持重置记录的版本。

“停止同步”取消本轮操作，已完整上传的分块可在下次继续使用。手动同步开始前保存分类、偏好、笔记和阅读位置，下载内容先校验并暂存，应用前再次保存打开的编辑器；保存失败时结束本轮同步并显示失败提示，云端内容不覆盖未保存的本地修改。网络期间的新本地修改会留到后续一轮处理，并继续显示未同步状态。应用中断后根据本地恢复记录完成清理或回滚。“关闭此书库同步”暂停当前书库的自动和手动同步，保留连接、设备身份、同步历史和云端数据。重新开启后继续推送关闭期间的修改与删除，不会把已删除文档当成新内容下载。

## 存储与限制

文件以 4 MiB 分块保存，未变化的文件不重复上传。每个设备维护独立的精简索引；每篇论文的元数据存入 `documents/<论文ID>/`，按 `original`、`translation`、`other` 分为原文件信息、译文排版和其他记录，`versions` 保存完整版本引用。`library/` 保存分类与书库对话。文件内容继续存入按哈希去重的 `objects/`；原文件、译文和笔记各自变化时仅上传改变的分块或元数据。元数据不可变，全部文件就绪后才提交设备索引，其他设备不会读到混合版本。坚果云免费账户有请求频率限制，应用将单个请求至少间隔 3.1 秒；首轮同步大书库需要较长时间，遇到限流后等待再试。

新版每篇论文的每个元数据部分及设备精简索引各自有 64 MiB 上限，不再由整库完整记录共用一份大清单。本地同步状态也按论文保存，提交小索引后再回收无引用的旧状态文件。本地同步缓存会占用额外磁盘空间；成功同步后自动回收不再被本地同步身份、基线或缓存的远端版本引用的文件分块。未解决冲突及暂停连接所需的缓存继续保留，恢复未完成或版本记录无法读取时跳过回收。永久删除通过删除记录传播，云端旧分块仍可能存在，彻底移除云端副本需在所有设备断开后手动删除对应目录。

首次打开新版时自动升级旧的本地同步状态；首次连接旧版云端清单时自动升级为新版目录。迁移保留本地 `state-v1.backup.json` 和云端 `.legacy/devices/` 备份，先写完整内容再提交新索引；中断后继续，不移动或删除原 PDF、EPUB、译文、笔记和批注。云端索引升级后，旧版客户端会因格式不兼容停止同步，参与同一书库的设备应一起升级。

修改时间用于展示和合并阅读进度；同步先后由记录的版本关系确认，迟到的同步不会仅因上传时间较晚就覆盖更新内容。双方离线修改同一份笔记时仍保留版本选择；删除使用显式删除记录传播。

账号和应用密码保存在本机书库的 `webdav-sync.json`；桌面版在应用用户数据目录的 `webdav-connection.json` 中保存共用连接。文件权限为当前用户读写，不随同步上传。云端正文和文件通过 HTTPS 传输，按普通坚果云文件保存。

## 手动验收

1. 在测试独立书库中同时放入论文和图书，添加笔记、批注、译文和两组聊天会话。保存同步设置，确认坚果云出现 `NeoRead/<书库名称>/`，间隔默认为 15 分钟。
2. 将间隔改成自填的 7 分钟，保存后重新打开设置确认。切换到另一个独立书库，确认默认未连接。
3. 在另一设备的同名空书库连接并同步，确认两类文档都可打开，阅读位置、笔记、译文、聊天顺序和分类一致。
4. 两台设备分别修改不同内容后同步，确认自动合并；离线修改同一篇笔记的不同正文后同步，确认出现版本选择并保留两份预览。
5. 重命名本地书库后同步，再在另一设备同步，确认只访问新目录。使用已存在的云端目录名更名，确认原目录没有被覆盖。
6. 上传期间停止同步或断网，恢复后重试；确认本地文档保留，已上传分块无需重传。同步下载期间继续编辑笔记，确认新修改没有被远端覆盖。
7. 检查书库选择右侧和阅读返回按钮右侧的图标位置；未配置时无图标，已配置未开启时只有空心双箭头，点击会打开同步设置。同步中没有中心符号，完成后勾变为静止，新笔记编辑后变为感叹号。
8. 制造一次手动同步失败，确认红色提示及叉号；继续编辑不能清除叉号，重试成功后出现绿色提示和勾号。自动同步失败只提示一次该轮结果，后续状态轮询不重复弹窗。
9. 在笔记冲突中先选择“稍后处理”，确认仍可阅读，再选择“都保留”，确认两份完整正文均存在，另一设备接收后再次同步不重复提示。
10. 关闭同步后删除一篇已同步论文，重新开启并同步，确认其他设备也删除该论文。两篇文档共用同一附件时，删除其中一篇应保留另一篇的附件。
11. 从空库接收至少两篇 PDF：第一篇原文件到达后应立即可读，译文和笔记继续补齐，随后第二篇出现。中途继续阅读第一篇、停止同步并重启，重试后进度与本地新笔记保留。
12. 在旧版测试同步数据上启动新版，确认本地和云端备份保留；修改一篇笔记后，未变的原 PDF 和其他论文元数据无需重传。设备改名后同步，云端设备索引显示新名称，设备 ID 保持不变。

自动回归使用隔离 WebDAV 服务验证双设备同步、冲突、重命名、凭据边界、文件恢复和编辑保护；实际坚果云账号的连接与限流表现需按以上步骤验收。
