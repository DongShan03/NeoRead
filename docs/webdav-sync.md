# 坚果云同步

在“设置 → 论文库 → 坚果云同步”填写坚果云账号邮箱和第三方应用密码，点击“保存”。应用密码可在坚果云网页的“账户信息 → 安全选项 → 第三方应用管理”中生成，见[官方说明](https://help.jianguoyun.com/?p=2064)。

保存时创建 `NeoRead/<当前书库名称>/`，默认是 `NeoRead/论文库/`。同步覆盖左上角选中的整个独立书库，包括其中的论文和图书。其他独立书库默认关闭，需要切换后分别配置。只有当前打开的独立书库会执行自动同步。

自动同步默认间隔 15 分钟，提供 5、10、15、30、60 分钟建议，也可填写 1–525600 的整数分钟。保存设置后按该间隔执行；点击“立即同步”可马上开始。关闭自动同步后仍可手动同步。

## 另一台设备

在另一台设备创建或选择同名独立书库，使用相同坚果云账号保存设置，然后点击“立即同步”。本地已有文档会参与双向合并；空书库会接收云端内容。可为设备填写不同名称，便于处理冲突。

原始 PDF/EPUB、论文信息和添加日期、分类与标签、回收站状态、批注、阅读位置、论文笔记、已保存的译文与公式、解析图片和缓存、文档附件、概要、已保存的聊天会话及消息均参与同步。独立书库中的论文视图与图书视图一起同步。

AI 账号与 API 密钥、CLI 登录与原生续聊线程、代理、机器路径、运行中的任务和诊断日志留在本机。进行中的解析、翻译和问答会延后同步对应文档；接收已有解析结果后可以直接阅读，未完成的翻译需手动继续。没有解析结果的 PDF 在本机排队解析，不自动调用翻译服务。搜索用的全文索引在接收端重新构建。

## 更名和冲突

双击左上角书库标题重命名后，下次同步会将云端文件夹一并更名。已连接设备通过稳定书库标识找到新路径，不重新创建旧目录。未激活书库的更名会排队，切回该书库后的下次同步执行。云端已有同名文件夹时停止更名并提示，需为本地书库换名。

修改不同笔记、批注或聊天会话时可以自动合并；多台设备同时修改同一内容时，在设置中显示“选择版本”。可查看设备名、时间和笔记或聊天摘录，再选择要保留的整篇文档版本。未选择前保留本地内容和云端各版本。阅读位置按实际阅读时间选择，最远阅读进度保留较大值。

“停止同步”取消本轮操作，已完整上传的分块可在下次继续使用。下载内容先校验并暂存，应用前保存打开的笔记与阅读位置；网络期间的新本地修改会留到后续一轮处理。应用中断后根据本地恢复记录完成清理或回滚。“断开连接”移除当前书库的连接设置和复制账本，保留本地书库与云端数据。

## 存储与限制

文件以 4 MiB 分块保存，未变化的文件不重复上传。每个设备写入自己的元数据清单，避免多设备覆盖同一索引。坚果云免费账户有请求频率限制，应用将单个请求至少间隔 3.1 秒；首轮同步大书库需要较长时间，遇到限流后等待再试。

当前格式的单设备元数据清单上限为 64 MiB，包含文档记录、笔记、聊天和分块索引；超限时提示拆分独立书库。本地同步缓存会占用额外磁盘空间；旧文件分块暂不自动清理。永久删除通过删除记录传播，云端旧分块仍可能存在，彻底移除云端副本需在所有设备断开后手动删除对应目录。

账号和应用密码只保存在本机书库的 `webdav-sync.json`，文件权限为当前用户读写，不随同步上传。云端正文和文件通过 HTTPS 传输，按普通坚果云文件保存。

## 手动验收

1. 在测试独立书库中同时放入论文和图书，添加笔记、批注、译文和两组聊天会话。保存同步设置，确认坚果云出现 `NeoRead/<书库名称>/`，间隔默认为 15 分钟。
2. 将间隔改成自填的 7 分钟，保存后重新打开设置确认。切换到另一个独立书库，确认默认未连接。
3. 在另一设备的同名空书库连接并同步，确认两类文档都可打开，阅读位置、笔记、译文、聊天顺序和分类一致。
4. 两台设备分别修改不同内容后同步，确认自动合并；离线修改同一篇笔记的不同正文后同步，确认出现版本选择并保留两份预览。
5. 重命名本地书库后同步，再在另一设备同步，确认只访问新目录。使用已存在的云端目录名更名，确认原目录没有被覆盖。
6. 上传期间停止同步或断网，恢复后重试；确认本地文档保留，已上传分块无需重传。同步下载期间继续编辑笔记，确认新修改没有被远端覆盖。

自动回归使用隔离 WebDAV 服务验证双设备同步、冲突、重命名、凭据边界、文件恢复和编辑保护；实际坚果云账号的连接与限流表现需按以上步骤验收。
